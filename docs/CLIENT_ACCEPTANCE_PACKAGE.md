# Client Acceptance Package

The client acceptance package is the final demo-to-build handoff layer.

It combines:

- acceptance criteria,
- test scenarios,
- demo script,
- build package,
- handoff decision.

## Purpose

This package helps decide whether a custom FinanceOps Agent implementation can move forward.

It should answer:

- did the demo cover the right workflow,
- are client data requirements clear,
- are blockers visible,
- are outputs traceable,
- are approval gates documented,
- is the next build step safe.

## Status values

The acceptance package can be:

- accepted,
- accepted with warnings,
- blocked.

Blocked means required client data or governance confirmation is still missing.

## Related pilot plan

After acceptance, the pilot plan defines what can safely be included in a limited pilot, which risks remain open, and how pilot success will be measured.
