# Client Pilot Plan

The client pilot plan turns the acceptance package into a limited pilot decision.

It includes:

- pilot scope,
- pilot risk register,
- pilot success metrics,
- pilot decision.

## Purpose

The pilot layer defines what can safely be demonstrated before production credentials, final mappings, and payment data are available.

## Key rule

A blocked production workflow can still be shown in a controlled demo, but it should not be included in a production pilot until missing client data and approval rules are resolved.
